# willard-peak-campground

A single-file marketing website for a Willard Peak campground in Willard, Utah.

## Features

- Editorial landing page: hero ("At the base of the Wasatch"), curated-radius attractions, site features (full hookup, dark sky, sauna stargazing), guest log/testimonials, and CTAs ("Check Availability", "Call — (435) 723-4567")
- Local context copy: Willard Bay, Willard Canyon, Brigham City, Golden Spike National Historical Park

## Tech stack

- One bundled HTML file (`willard_x5f_peak_x5f_campground_x5f_elegant (2).html`): React (compiled in-page) + Tailwind styles, self-contained

## Getting started

No build step — open the HTML file directly in a browser.

## Project structure

- `willard_x5f_peak_x5f_campground_x5f_elegant (2).html` — the whole site
- `README.md` — was just a heading; this file replaces it

## Status

Content-complete static page. Note: the phone number, address details, and reviews in the copy are part of the page content — verify them before publishing as a real business site.
